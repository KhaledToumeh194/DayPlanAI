# DayPlan

DayPlan is a personal AI-powered daily planner.

Instead of manually organizing every task, the user can describe what
they need to do in natural language and DayPlan builds a realistic plan
for the day.

## Tech stack

### Frontend

- React
- TypeScript
- Vite
- TanStack Router
- Tailwind CSS

### Backend

- Node.js
- Express

### Database

- SQLite

## Current features

- Create tasks
- View tasks
- Complete/uncomplete tasks
- Delete tasks
- Task priority
- Due dates
- SQLite persistence
- React frontend connected to Express API

## In progress

- AI-generated daily plans
- Gemini integration
- Plan history

## Run locally

### Backend

```bash
cd backend
npm install
node server.js
```
